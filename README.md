# 位享

找目的地附近的公共停车场，也把家里空着的车位租出去。同一个人可以找车位、当房东，也可以租别人的车位。

第一版是一套响应式网站。手机和电脑共用一个界面，链接可以直接转发。原生 App 和小程序留到交易闭环跑通之后。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run setup
npm run dev
```

打开 http://localhost:3000 。

`npm run setup` 会重建 SQLite，并写入演示数据。数据库文件在 `prisma/dev.db`。

## 环境变量

复制 `.env.example` 为 `.env`。

- `SMTP_*`：验证码邮件。生产环境必须配置。
- `AMAP_WEB_KEY` / `BAIDU_MAP_AK` / `TENCENT_MAP_KEY`：地图开放平台密钥。只填哪个就用哪个。
- `TRUST_PROXY=true`：只在 Nginx 等可信代理后面打开，并让代理写入 `X-Real-IP`。
- `PARKING_INGRESS_TOKEN`：车场系统回传余位的凭证。
- `CODE_PEPPER`：验证码哈希用的胡椒，生产环境换成随机长字符串。

## 这一版做了什么

- 邮箱验证码注册、密码登录、忘记密码重置。
- 同一账号同一时间只绑定一个网络地址。同一台电脑的多个窗口可以，因为它们是同一个地址。换网络要用邮箱验证码改绑。
- 按城市和地标查找已收录的公共停车场，展示收费、外来车政策、固定车位、临停车位和可用车位。
- 配置了地图开放平台密钥后，搜索目的地会合并官方周边检索结果。收费和余位不会靠猜，需要人工补全。
- 用户上报停车场，管理员审核通过后记 80 积分。
- 房东发布车位，可按小时、白天、夜间、月、年，或春节、国庆这类整段档期出租。
- 下单时检测时段冲突。10 积分抵 1 元。平台按租金的 8% 记服务费，积分抵扣由平台补贴给车主。
- 订单对话。进场说明在锁定时段后才对租客可见。
- 管理后台维护停车场、审核上报、开关首页广告位。
- `POST /api/open/availability` 预留给车场系统回传可用车位。

现金支付这一版只记账。接入微信支付后再真正扣款。

## 为什么不爬地图

高德、百度、腾讯的 App 页面和私有接口都不允许拿来抓取。那样做不稳定，也违反它们的服务条款。位享只接三家开放平台的正式 Web 服务：地理编码和周边停车场检索。密钥、配额和商用授权需要在对应开放平台申请。

坐标系会从 GCJ-02 或 BD-09 转成 WGS-84 再和站内数据放在一起。这只是为了对齐位置，不是另一份底图。

## 云服务器

面向国内用户，第一版建议放在国内云，并完成 ICP 备案。阿里云或腾讯云都可以。更常和高德、对象存储、短信放在一个账号里时，选阿里云；团队更熟腾讯地图和微信支付时，选腾讯云。

早期一台就够，不要一上来买大规格：

- 应用：2 vCPU，4 GB 内存，60 GB ESSD，带宽按量或固定 5 Mbps，Ubuntu 24.04。
- 数据库：云厂商 PostgreSQL 基础版，1 vCPU 2 GB。单机演示可以用现在这套 SQLite，一旦要开第二台服务器就不能再用 SQLite。
- 对象存储：车位照片以后放 OSS 或 COS。
- 域名、免费 SSL 证书、企业邮箱或邮件推送。
- 备案期间如果只是给自己看，可以临时用香港节点，不适合作为正式入口。

还要做的事：企业主体、隐私政策、用户协议、地图商用密钥、邮件发信域名、数据库每日备份、Nginx 反代和 `TRUST_PROXY`。支付、退款和对账是下一阶段，不在这一版里假装已经完成。
